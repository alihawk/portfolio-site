# Portfolio

Source for my personal website, [alimahmood.dev](https://alimahmood.dev).

It's a single static page built with plain HTML, CSS and JavaScript, with no framework and no build step.

## Running locally

```bash
npm start          # serves the site with npx serve
```

Or just open `index.html` in a browser.

## Deploying

```bash
npm run deploy:vercel
# or
npm run deploy:netlify
```
